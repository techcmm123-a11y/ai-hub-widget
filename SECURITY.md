# Security Policy / Политика безопасности

## Supported versions / Поддерживаемые версии

Only the latest release receives fixes. / Исправления выходят только для последней версии.

## Reporting a vulnerability / Как сообщить об уязвимости

Please **do not** open a public issue for security problems.
Use GitHub: **Security tab, Report a vulnerability** (private reporting).

Пожалуйста, **не создавайте** публичный Issue для проблем безопасности.
Используйте GitHub: вкладка **Security, Report a vulnerability** (приватное сообщение).

Please include / Укажите: version, Android version and device, steps to reproduce, impact.

The app has no permissions and no network access, so typical issues are about: link handling, widget broadcasts,
backup restore, and the signing/build process. This is a hobby project: reports are handled on a best-effort basis.
